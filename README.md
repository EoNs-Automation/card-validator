# Card Validator

A simple credit/debit card number validator that uses the Luhn Algorithm.

## Features

- Validates card numbers using the Luhn Algorithm
- Detects card type (Visa, Mastercard, American Express, Discover, etc.)
- Shows expected length for each card type
- Available as both a Python script and a web tool

## Live Demo

[Try the web version here](https://card-validator-1ae86d.netlify.app/)

## How to Use (Python)

1. Run the script
2. Enter a card number
3. See if it’s valid and what type of card it is
4. Type `quit` to exit

## Example
Enter card number: 4111111111111111
Card Type: Visa
Length: 16 (Expected: 13-19)
Status: VALID!
